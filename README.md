# My Portfolio Website

A simple, clean portfolio website built with plain HTML and CSS hosted on GitHub Pages.

## Features

- 📱 Fully responsive design
- 🎨 Modern styling with CSS Grid and Flexbox
- 📧 Contact section with social links
- 🚀 Lightweight and fast
- 💻 No dependencies needed

## Sections

- **Home**: Hero section with welcome message
- **About**: Brief bio and skills showcase
- **Projects**: Display your projects in a grid layout
- **Contact**: Links to email, GitHub, LinkedIn, and more

## How to Customize

### Update Your Information

1. Open `index.html` and replace:
   - "My Portfolio" with your name
   - Update the About section with your bio
   - Replace project descriptions with your actual projects
   - Update contact links (email, GitHub, LinkedIn, etc.)

### Customize Styling

Edit `style.css` to change:
- Colors: Look for hex codes like `#667eea`, `#3498db`
- Fonts: Modify the `font-family` in the `body` selector
- Layout: Adjust spacing and sizes as needed

### Add More Sections

Simply follow this pattern in `index.html`:
```html
<section id="section-name" class="section-name">
    <div class="container">
        <!-- Your content here -->
    </div>
</section>
```

Then add corresponding styles in `style.css`.

## Deployment

Your site is automatically deployed to `https://nameless0714.github.io` via GitHub Pages!

Just push your changes to the main branch and they'll be live within seconds.
